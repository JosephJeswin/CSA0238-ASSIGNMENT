# AI-Based Traffic Congestion Prediction and Intelligent Route Optimization Using Ant Colony Optimization (ACO)

## Project Title

AI-Based Traffic Congestion Prediction and Intelligent Route Optimization Using Ant Colony Optimization

## Features

- Traffic congestion prediction using a Random Forest classifier trained on a real CSV dataset.
- Automatic dataset inspection for numerical, categorical, and target columns.
- Missing-value handling, categorical encoding, and train/test preprocessing with stratified split.
- ACO-based route optimization that minimizes traffic-adjusted travel cost.
- Scenario-aware network updates for Normal, Morning Rush Hour, Accident Incident, and Bad Weather Storm.
- Flask REST APIs for prediction, training, route optimization, comparison, and dataset analysis.
- SQLite logging for prediction and route queries.
- React + Vite dashboard for exploring datasets and visualizing results.

## Dataset

Place your Kaggle CSV file in `backend/data/traffic_data.csv`.

The project automatically inspects the CSV to detect:
- numerical features such as speed, traffic density, vehicle count, occupancy, flow, queue, delay, and acceleration
- categorical features such as weather, time, road type, incident status, signal timing, and environment
- target columns such as `congestion_level`, `congestion`, `label`, and `target`

All summary statistics are generated from the actual dataset loaded from disk.

## Machine Learning

The project uses a `RandomForestClassifier` trained with a stratified 80/20 train-test split.

Metrics generated by the model include:
- Accuracy
- Precision
- Recall
- F1-score
- Macro F1
- Weighted F1
- Confusion matrix
- Classification report
- Feature importance

## ACO Algorithm

The route optimizer is implemented manually in `backend/aco.py` without NetworkX.

Core steps:
- Graph creation from the road network
- Pheromone initialization
- Ant construction of routes
- Heuristic calculation using inverse edge cost
- transition probability based on pheromone and heuristic values
- evaporation and pheromone deposition
- best-route tracking across iterations
- convergence trace storage

## Architecture

The project is structured into a Flask backend and a React frontend.

- `backend/app.py` – Flask API and route handling
- `backend/preprocessing.py` – dataset inspection and preprocessing pipeline
- `backend/ml_model.py` – Random Forest model training and evaluation
- `backend/aco.py` – Ant Colony Optimization implementation
- `backend/road_network.py` – traffic-aware graph and scenario definitions
- `backend/database.py` – SQLite logging
- `frontend/src` – React dashboard and interface

## Project Limitations

- The example dataset is a demonstration dataset included in the repository for local execution.
- The route network is a simplified academic road graph rather than a full city-scale GIS map.
- ACO performance depends on graph size, parameter tuning, and scenario definitions.
